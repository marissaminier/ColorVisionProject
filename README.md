# Colorblind Friendly Calculator

## Description

**version 1.0**

This program allows the user to enter 1 to 3 colors, 
and tells the user if their color/color combination is colorblind friendly.

## Developer

Marissa Minier

## Example

To run the program, give the following commands:

```
g++ --std=c++11 *.cpp -o cvp
./cvp
```

Here is an example of the program running:

```
Welcome to the colorblind friendly program! 
I can help give you a general idea of which colors and color combinations are colorblind friendly. 
How many colors ware you working with? (3 maximum): 3 

Enter color 1: Red 
Red is typically not colorblind friendly. 

Enter color 2: Green 
Green is typically not colorblind friendly. 

Enter color 3: Purple 
Good choice! Purple is typically colorblind friendly. 

Results:
Your color/color combination isn't very colorblind friendly.
```
